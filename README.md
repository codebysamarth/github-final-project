# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a project that calculates simple interest using the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

* **Principal (P):** The initial amount of money.
* **Rate (R):** The annual rate of interest expressed as a percentage.
* **Time (T):** The investment or loan period in years.

## Features

* Accepts the principal amount as input.
* Accepts the annual rate of interest as input.
* Accepts the time period in years.
* Calculates and displays the simple interest.

## Technology Used

* Bash
* Git
* GitHub

## Usage

Run the `simple-interest.sh` script in a Bash terminal and enter the requested values.
